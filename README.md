# hello-plugin

Starter Claude Code plugin, distributed via [rajib-skill-marketplace](https://github.com/rajib76/rajib-skill-marketplace).

## Install

```
/plugin marketplace add rajib76/rajib-skill-marketplace
/plugin install hello-plugin@rajib-skill-marketplace
```

## Layout

```
.claude-plugin/plugin.json   # plugin manifest
skills/hello/SKILL.md        # the "hello" skill
```
